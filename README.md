# CurrentAppGuardian - High-Performance Video Player

## 功能特性

### 🎬 核心播放功能
- **Media3 / ExoPlayer** 原生 Android 播放核心
- 支持 **MP4 / HLS / DASH** 多種串流格式
- 支持 **HTTP/HTTPS** 網路影片
- **硬體解碼優先** 減少 CPU 負擔
- 無廣告 - 完全自控的播放體驗

### 🌐 網路管理
- **網路連線監測** - 實時偵測 WiFi 和行動網路
- **Wi-Fi／行動網路切換偵測** - 自動偵測網路變化
- **斷線後保留播放器狀態** - 記憶播放位置和設定
- **網路恢復後自動恢復** - 無縫恢復播放
- **網路速度即時估算** - 根據頻寬動態調整

### 📊 智慧緩衝系統
- **卡頓趨勢偵測** - 主動檢測即將卡頓
- **卡頓風險升高時限制位元率** - 提前降低畫質避免卡頓
- **根據網速動態調整緩衝策略** - 智慧緩衝管理
- **卡頓前提前降低畫質** - 預測性畫質調整
- **卡頓後逐步恢復畫質** - 平穩質量升級

### 🔧 播放控制
- **自動畫質** - 根據網路自動選擇最佳畫質
- **手動選畫質** - 支援 1080p / 720p / 480p / 360p
- **倍速播放** - 支援 0.5× 至 2.0× 倍速
- **快轉／倒退** - ±10 秒精確調整
- **全螢幕** - 沉浸式觀看體驗
- **音量／亮度手勢** - 直觀的手勢控制

### 💾 狀態保存
- **播放位置記憶** - 自動保留播放進度
- **播放設定保存** - 記憶倍速、全螢幕、音量等
- **MP4 / HLS / DASH 支援** - 所有格式都能保存狀態

### 🚀 性能優化
- **低記憶體裝置最佳化** - 高效率的資源使用
- **Android 11+ 相容** - 確保最新裝置支援
- **預載入架構** - 下一個影片提前準備
- **播放清單快取** - 減少網路請求

### 🎯 YouTube 整合
- **YouTube 首頁入口** - 一打開就連著 YouTube
- **YouTube 影片嵌入播放** - 支持直接播放 YouTube 影片
- **無廣告體驗** - 使用原生播放器規避廣告

### 🔄 錯誤恢復
- **播放錯誤分級恢復** - 最多 4 次遞進式恢復
- **避免無限循環** - 智慧錯誤檢測機制
- **播放錯誤自動重試** - 網路異常時自動恢復

## 系統要求
- **Android**: 11 及以上
- **Java**: JDK 17
- **Gradle**: 9.5
- **AGP**: 9.3.0

## 快速開始

### 編譯
```bash
./gradlew build
```

### 安裝到裝置
```bash
./gradlew installDebug
```

### 執行
```bash
./gradlew run
```

## 架構設計

### 核心模組
1. **NetworkMonitor** - 監測網路狀態和頻寬
2. **SmartBufferingManager** - 動態緩衝管理
3. **PlaybackStateManager** - 播放狀態持久化
4. **PlaybackErrorHandler** - 錯誤恢復邏輯
5. **MainActivity** - 播放 UI 和控制
6. **YouTubeActivity** - YouTube 整合

### 技術堆棧
- **Media3 1.1.1** - 最新的 Android 媒體框架
- **ExoPlayer** - 強大的影片播放引擎
- **Kotlin Coroutines** - 非同步任務管理
- **DataStore** - 輕量級數據持久化
- **Material Design** - 現代化 UI
